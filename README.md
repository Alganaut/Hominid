### Description

Hominid is a mod featuring the long gone humans of the Minecraft world.

These new monsters bring some variation to combat and can make certain biomes more challenging, 
as generic mobs are replaced with variants that better fit their environment. 
Hominid's mobs vary in rarity and behaviour, which means they can each provide different threats and encounters.
